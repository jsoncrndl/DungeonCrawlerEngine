# Dungeon Crawler Engine
A WIP runtime and editor for a top-down dungeon crawler.

The engine will be able to load any game built in the editor in a single file. You will be able to make a dungeon, share it with your friends, and play together online.

## Completed:
- Basic graphics API

## In-Progress:
- ECS framework
- Memory management
- Reflection
- Serialization
